## Key Patterns Summary

| Pattern | When to Use |
|---------|-------------|
| Hero-Centric + Social Proof | Products with emotional/visual appeal (spa, hotel, travel) |
| Feature-Rich Showcase | SaaS, e-commerce, apps with many features |
| Trust & Authority | Finance, legal, B2B — credibility is core |
| Storytelling-Driven | Brands, agencies, nonprofits, portfolios |
| Data-Dense Dashboard | Analytics, finance, IoT, real-time systems |
| Conversion-Optimized | Lead gen, sales pages, subscriptions |
| Interactive Demo | Software tools, SaaS products |
| Minimal & Direct | Simple apps, documentation, knowledge bases |
