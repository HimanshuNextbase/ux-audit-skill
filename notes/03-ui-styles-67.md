## Style Selection Framework

When choosing a style, match against:
1. **Product type** — Use `ui-reasoning.csv` to find recommended style for your industry
2. **Audience** — Gen Z → Neubrutalism/Y2K; Enterprise → Minimalism/Swiss; Wellness → Neumorphism/Organic
3. **Platform** — iOS → HIG idioms; Android → Material; Web → your choice
4. **Performance needs** — High performance required → avoid 3D/Heavy styles
5. **Accessibility requirements** — Government/Healthcare → WCAG AAA styles only

### Key Anti-Patterns to Avoid
- Mixing flat + skeuomorphic randomly
- Emoji as structural icons (always use SVG)
- AI purple/pink gradients for banking, legal, healthcare (screams generic AI)
- Dark mode by default for wellness/spa
- Harsh animations for calm/wellness products
- Playful design for finance/legal/government
